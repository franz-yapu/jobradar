---
name: task-brief
description: Before writing an SDD, verify the ticket's premises against the repo and the PRD. Use when starting any new ticket.
---
1. Read the ticket and docs/product/PRD.md.
2. Search the repo for related code, ports and existing modules.
3. List: what exists, what is missing, open questions, risks.
4. Output a short brief (max 1 page) and ask for confirmation before the SDD.
